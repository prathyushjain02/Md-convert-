    PDFs are read with layout analysis, so tables keep their shape and multi-column pages stay in reading order. Images and audio yield metadata, plus transcription when those optional tools are available on the server. Zip archives are unpacked and every file inside is converted.

    Use it from the command line 
    curl -X POST -F "files=@report.pdf" \
  https://YOUR-APP.onrender.com/api/convert/file -o report.md

    Post several files and you get a markdown.zip back. For JSON instead of a file, post to /api/convert.

    Files are converted on the server in a temporary directory that is deleted as soon as the response is sent. Nothing is stored, logged or shared.
